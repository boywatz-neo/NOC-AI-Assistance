# Project Management

This folder contains project-management artifacts for the NOC AI Assistant MVP. These files translate the product and technical specs into planning, tracking, delivery, and governance documents.

## Files

- `Epic.md`: large feature areas that keep the project aligned to the MVP objective.
- `User-Stories.md`: user-centered stories mapped to epics.
- `Tasks.md`: implementation task backlog with priority, phase, and dependencies.
- `Milestones.md`: delivery milestones and acceptance gates.
- `Acceptance-Criteria.md`: MVP acceptance criteria and release gates.
- `RAID-Log.md`: risks, assumptions, issues, and dependencies.
- `RACI.md`: responsibility matrix.
- `Release-Plan.md`: release strategy for MVP, staging, and production.
- `Change-Control.md`: process for scope and spec changes.

## Planning Rule

Use the specs in `spec/` as the source of truth. Update project-management artifacts when scope, architecture, API contracts, database design, or deployment assumptions change.
